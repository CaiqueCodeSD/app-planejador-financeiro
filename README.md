# Planejador Financeiro

O **Planejador Financeiro** é um aplicativo Android em desenvolvimento, criado com o objetivo de facilitar a organização e o acompanhamento das finanças pessoais por meio de uma interface intuitiva, moderna e minimalista.

O projeto busca oferecer ao usuário uma visão clara de suas receitas, despesas e resultados financeiros, priorizando a simplicidade de uso, a privacidade e o controle sobre os próprios dados.

## Objetivos

- Facilitar o registro e o acompanhamento das receitas e despesas.
- Apresentar um resumo da situação financeira mensal e anual.
- Disponibilizar gráficos e relatórios para auxiliar na compreensão dos hábitos financeiros.
- Permitir o acesso aos dados mesmo sem conexão com a internet.
- Explorar uma estratégia de sincronização com o Google Sheets, oferecendo maior flexibilidade no gerenciamento dos dados.

## Tecnologias

- **Kotlin** — linguagem principal do aplicativo.
- **Android SDK** — desenvolvimento para a plataforma Android.
- **XML e Views** — construção das interfaces.
- **Android Studio** — ambiente de desenvolvimento.
- **Room** — persistência local planejada para o funcionamento offline.
- **Google Sheets API** — integração planejada para sincronização dos dados.

## Status do projeto

O projeto está em desenvolvimento. A implementação será realizada de forma incremental, com foco na organização do código, na qualidade da arquitetura, na experiência do usuário e na aplicação de boas práticas de desenvolvimento Android.

## Propósito

Além de ser uma ferramenta de organização financeira pessoal, o Planejador Financeiro é um projeto de portfólio desenvolvido para aprofundar conhecimentos em desenvolvimento Android nativo, arquitetura de software, persistência de dados, sincronização e versionamento com Git.
